Privacy Policy

Last updated: September 3, 2026

This policy describes how the private Ameen Calendar Bridge accesses and uses Google user data for Mohammad Raafi Hossain. The integration has one known user and is not a public service.

Data accessed

The bridge requests only the Google Calendar list read-only and Calendar events read-only scopes. It reads the owner's primary calendar and uses only event summary, start and end time, recurrence reference, the owner's response state, and transparency. Descriptions, locations, attachments, meeting links, and attendee lists are excluded by the bridge.

Use and sharing

Minimized calendar data is used only to answer the owner's requests and support private scheduling context. When needed for an authorized Ameen response, those minimized fields may be processed by the owner's configured model provider, currently OpenAI. Data is not sold, used for advertising, or shared for unrelated purposes.

Storage and security

The Source Broker does not persist Google Calendar response bodies. OAuth credentials are held outside the assistant runtime in a locked host credential. Minimized information may appear in an owner-requested private conversation or governed private memory. It is not placed in a public repository.

Control and deletion

The owner can revoke access at any time from Google Account permissions. Revocation stops future access. The operator can also remove the locked credential and any deliberately retained private notes derived from the connection.

Google API policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
